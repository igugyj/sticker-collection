# Personal Sticker Library

## Project Structure

```shell
- sticker-collection
  - README.md           // Project description
  - scripts             // Scripts folder
  - emoCut.py           // Image cropping tool
  - lib                 // Sticker library
    - folder1           // First sticker folder
    - folder2           // Second sticker folder
     ...
  - requirements.txt    // Dependencies
```

## Usage Instructions

1. To use [EweSticker](https://github.com/FredHappyface/Android.EweSticker), set the `lib` folder as the sticker folder in the app.
2. `emoCut.py` is an image cropping tool that can split large images into small stickers. See the comments in the file for usage details.
3. All files in the sticker library are sourced from the internet.

### Usage

git history is **heavy**, to use it, clone the repo or download a folder via some [plugins](https://addons.mozilla.org/firefox/addon/gitzip/).

e.g.

```shell
git clone --depth 1 https://github.com/igugyj/sticker-collection.git # HTTPS
# or
git clone --depth 1 git@github.com:igugyj/sticker-collection.git # SSH
```
